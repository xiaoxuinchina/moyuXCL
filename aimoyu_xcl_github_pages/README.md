# 爱摸鱼的XCL · GitHub Pages 上传版

把此文件夹内的所有文件上传到 GitHub 仓库根目录，然后在 Settings → Pages 中选择：

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

需要上传的文件：

- index.html
- manifest.json
- service-worker.js
- xcl_avatar.jpg
- icon-192.png
- icon-512.png

部署后访问：
https://你的GitHub用户名.github.io/仓库名/

Android Chrome 打开后可通过“添加到主屏幕/安装应用”安装为 PWA。
