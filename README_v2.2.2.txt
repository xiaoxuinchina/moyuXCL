爱摸鱼的XCL · Mobile v2.2.2

本次更新：
1. 每条记录新增“修改”按钮。
2. 可以补录旧记录缺失的活动时长。
3. 修改时可调整分类、标题、备注、结果、活动时长和日期。
4. 新增 version.json 自动版本检测。
5. APP 启动、回到前台、页面恢复时都会检查线上版本。
6. 新版本发布后会自动带版本参数重新加载，绕过 WebView/HTTP 缓存。
7. Service Worker 的页面导航改为 no-store 网络优先，只在断网时使用离线缓存。
8. Service Worker 更新后会自动刷新页面。

为什么以前需要清缓存：
- WebView 有 HTTP 缓存；
- Service Worker 又有独立缓存；
- Android 关闭 APP 不一定真正杀死 WebView 进程；
- 因此“重新打开”有时仍然会拿到旧 index.html。

从 v2.2.2 开始：
- version.json 使用 no-store 请求；
- 如果版本不同，自动加载带 appv/ts 参数的新页面；
- 因此以后正常情况下无需手动清缓存。

重要：
从旧版升级到 v2.2.2 这一次，如果手机仍一直展示旧页面，可能需要最后清一次“缓存”来让新的自动更新代码首次进入 WebView。
不要清除应用数据，否则本地历史记录会丢失。
