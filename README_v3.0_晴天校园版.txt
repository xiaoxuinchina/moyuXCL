爱摸鱼的XCL · Mobile v3.0 晴天云朵 × 清晨校园版

这是 v2.2.2 的视觉替换版。

保留不变：
- 添加/修改/删除记录
- 全部历史记录
- 活动时长统计
- 四区进度条按时长计算
- 摸鱼指数公式
- 当前时间与天气定位
- 自动版本检测和自动更新
- localStorage 键仍为 xcl-workbench-v1，因此原有记录不会因为换主题而丢失
- “专属头像卡”保持移除
- “欢迎来到你的二次元工作台主页”保持移除

本版仅重做视觉：
- 晴天云朵 + 清晨校园背景
- 全站浅色玻璃拟态
- 深蓝文字 + 天空蓝高亮
- 科研/摸鱼/生活/运动卡通贴纸图标
- 分区图标使用 CSS 浮动/摇摆动画，是真正网页动效，不需要 GIF
- 天气/时间/摸鱼指数加入卡通小插画
- 记录页、历史页、弹窗、底部导航同步统一为浅色风格

升级方法：
1. 解压后，把全部文件上传到原网页仓库 moyuXCL 根目录覆盖同名文件。
2. 不要上传到 moyuXCL-android。
3. WebView APK 不需要重新编译。
4. v2.2.2 已有自动更新逻辑，本版 version.json=3.0.0；正常情况下关闭再打开 APP 即可刷新。
5. 如果手机第一次仍卡在旧主题，只清“缓存”，不要清“数据”。
