爱摸鱼的XCL · Mobile v2.2.1 稳定修正版

核心修复：
1. 修复 v2.2 中 render() 函数被错误写入字面量 \n，导致整段 JavaScript 无法解析的问题。
2. 因此恢复：时间实时刷新、天气、所有按钮、分区切换、新增记录、历史记录、动态进度条和摸鱼指数。
3. 摸鱼指数 HTML 默认值由 68 改为中性值 50；运行后按公式实时计算。
4. 摸鱼指数公式：50 + 50 × (1.00×摸鱼时间 + 0.45×生活时间 + 0.15×运动时间 − 0.75×科研时间) / 总活动时间，并限制在 0–100。
5. 页面启动后自动尝试获取天气与位置。
6. todayISO 改为手机本地日期，避免 UTC 在午夜附近造成“今天”错位。
7. Service Worker 缓存更新为 v2.2.1。
